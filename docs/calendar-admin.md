# Calendar administration

The `/calendar` workspace page shows published entries, scheduled drafts and scheduled changes across collections in the site's configured time zone. It provides month and agenda views, collection/locale/state filters, month navigation and prefetching, entry details, overdue publication, schedule removal and rescheduling. Calendar discovery uses the existing `content:read_drafts` permission. Publishing actions use the original editor/own-author affordances and the existing lifecycle's publish permissions.

The entry panel reads the published content/byline/translation producers, retains `_rev` when publishing, and provides the original preview fallback and live URL patterns. Rescheduling reuses the published date/time fields, preserves an unchanged schedule, and prevents a completed submission for an earlier entry from closing a newly selected entry. Accepted actions invalidate the supplied page query client without waiting for subsequent refreshes. This feature adds no database, migration, alternate writer, role or query cache owner.
