# Native string/text pattern metadata

This milestone exposes persisted `validation.pattern` through the existing Kit schema forms. The behavior authority remains EmDash 1.1.0 at immutable [`913cb1bb9b7f08c3ff0d258b4420e53835b6a58e`](https://github.com/emdash-cms/emdash/commit/913cb1bb9b7f08c3ff0d258b4420e53835b6a58e). The [core/source record](pattern-validation.md) owns regex/content behavior and source assertion credit. These native interaction checks are supplemental framework tests and earn zero React, REST or MCP assertion credit. Preserve the [upstream MIT notice](../notices/emdash-MIT.txt).

Creation adds **Pattern metadata** (`patternMode`) and **Validation pattern** (`pattern`). `patternMode` defaults to `omit`; displayed blank text alone creates no validation pattern. Selecting `set` stores the exact submitted string, including `''`, whitespace and slash-looking sources. A selected source must be present and compile through `new RegExp(source)` without flags. Invalid syntax produces an issue at the native `pattern` field before the form callback and database write. The converter strips native instance and mode fields before the service revalidates the domain input. Creation retains its existing bounds/default length checks and does not regex-check a metadata default.

Existing field options retain `validationMode` **keep / set / clear**. Keep omits validation from the service input and ignores stale editor text. Set replaces the full object using displayed nonblank length bounds and the selected pattern. The replacement pattern mode initially selects `set` when stored `pattern !== undefined`, including an empty source; otherwise it selects `omit`. Selecting omit during replacement removes the old pattern key. Selecting set with blank text stores `{ pattern: '' }`; omitting the pattern and both bounds stores `{}`. Clear stores `null` and ignores pattern text. Existing content remains readable and metadata edits leave physical defaults, content rows and collection version/timestamp untouched.

The source is a JavaScript regular expression. It is case sensitive and unanchored unless the operator supplies anchors. A nonempty pattern checks optional supplied empty content values; an empty pattern disables the regex check. UI/preview controls do not copy this source into an HTML `pattern` attribute: HTML's whole-value matching and Unicode rules differ. The server remains authoritative for content validation. Pattern editing uses a textarea to preserve multiline display. Browser textarea display normalizes line endings to LF and native HTML encoding submits CRLF; newly entered sources store the exact submitted value, without an authored-byte fidelity claim. Existing options also submit an optional JSON-string `patternOriginal` snapshot. If the textarea is unchanged after line-ending normalization, the converter restores the original LF/CRLF/lone-CR source exactly; edited sources use the submitted text. The snapshot is untrusted form data, grants no authority, never enters service inputs, and the selected source still undergoes syntax and domain validation. Keep/clear ignore dormant snapshots. Malformed selected snapshots report the same native pattern issue.

The native interaction adds an explicit empty-source choice supported by the pinned API. Pinned admin `FieldEditor.tsx` uses a text input and includes a source only when truthy, so its empty editor omits the key. The local string/text source editor is a framework adaptation, and the text-field UI extension is a product scope decision; neither establishes React declaration parity or a specific acceptance decision. The [compatibility register](../parity/emdash/compatibility.md) owns the final decision status.

No production session/storage composition or mutation activation is included in this milestone. Controls inherit the existing trusted capability and default-disabled gate. Bypassing the disabled fieldset in the browser still receives `MUTATIONS_DISABLED` with zero writes.
