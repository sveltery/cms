# HTML blocks and embed controls

This dependent feature restores EmDash 1.1.0 HTML block editing, its inline and isolated previews, and the options card shared with iframe blocks. The behavior reference is immutable commit `913cb1bb9b7f08c3ff0d258b4420e53835b6a58e`.

The complete [original HTML editor and preview test file](../parity/emdash/rich-editor-source/packages/admin/tests/editor/html-block-editor.test.tsx) is retained without changing its callbacks, assertions, input data, mocks or clocks. It contains 28 cases: 21 editor cases and seven preview cases. The 54 direct `expect` calls and 65 static matcher expressions describe the source inventory, rather than a measured runtime assertion count. [The authority ledger](rich-editor-source.json) retains all earlier records and adds this whole family.

The editor contract includes real HTML, CSS and JavaScript CodeMirror tabs; per-field edits written together after 250 milliseconds; flushes before tab changes and outside actions; retained edits while read-only; undo synchronization; top-level placement; and focus after deletion or Escape. Saved blocks initially show Preview. The options menu switches inline and isolated rendering, and editable blocks expose Delete inside that menu. Controls follow the existing interface locale independently of the document's content direction.

Isolated previews require a Run preview decision for saved scripts, executable markup or nested frames. Inline previews use the original private DOMPurify instance and the site's shared allowed tags, attributes, URL schemes and iframe hosts. The admin preview uses exactly `sandbox="allow-scripts"`. Real intersection observation controls frame creation; messages must come from the current frame window and use the original message type. Finite heights are clamped to 0–20,000 pixels, the previous height survives tab changes, changed content creates a fresh frame, and drag events suspend frame pointer input. Security-policy reports use the original localized notice.
