# Public published-content rendering

This bounded feature adds anonymous `/site`, `/posts`, `/posts/[slug]` and `/pages/[slug]` views for real persisted `posts` and `pages` collections. Operators create those collections through the existing schema API and publish entries through the ordinary lifecycle service. Existing admin routes retain their present paths. An absent collection produces an empty archive or a 404 detail; absent configured storage remains unavailable.

The reader uses the existing pinned content repository, literal `published` status and active rows. Entry lookups preserve its ULID/slug fallback and locale-scoped slug behavior; globally unique ID lookups retain Source ID semantics. Reads use live content columns and never hydrate the staged revision. The public projection exposes declared content fields and public timestamps, omitting revision pointers and private author/version internals. Draft, unpublished and trashed entries produce 404 responses.

Portable Text renders paragraph/heading/span marks, safe links, grouped blockquotes, nested lists with numbered identity continuation, alignment classes and escaped plain code. The complete Source list, quote, alignment and URL implementations retain their bodies with native module/type imports. The Svelte transport and public HTML renderer are native adaptations. Existing `getSeoMeta` and `SeoHead` helpers generate ordinary title, description, canonical and article metadata from live values.
