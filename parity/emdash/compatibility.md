# Current compatibility register and historical audit

The default is the selected EmDash behavior on both self-hosted Node and Cloudflare. A passing scaffold build does not establish either hosting target. Keep differences visible and correct accidental divergence before widening the CMS surface.

## Current landed contracts

This index was verified against CMS main `8bd3e62fe131116670fea7b87e623ba30fd84b19`. Source authority is [EmDash 1.1.0](README.md), immutable pin `913cb1bb9b7f08c3ff0d258b4420e53835b6a58e`. The feature documents and assertion ledgers below retain detailed evidence; this index separates intentional substitutions/bounds, fidelity repairs and unimplemented scope. A merged PR establishes landed state, not specific approval of a deviation. The cited records do not document a specific acceptance decision for the intentional differences indexed here. Divergent assertions are not upstream passes.

## Historical scaffold-era decision statement and current policy

The scaffold-era planning PR recorded **no accepted domain behavior deviations**. That historical statement is not a claim that current main has no intentional differences; the landed contracts above now provide the current index. A different runtime transaction API, native remote envelope, or absent Astro type generator needs adaptation evidence; it does not automatically authorize a behavior change.

For each proposed deviation add: stable ID; exact upstream source IDs and assertions; baseline behavior; proposed observable difference; documented SvelteKit/Node/Cloudflare constraint with authoritative source; alternatives considered; affected runtimes/users/data; truthful decision status, landed PR; paired regression tests; migration and documentation requirements. Keep proposed, landed and specifically accepted statuses separate, with evidence for each transition. “Simpler”, “Cloudflare-first”, “temporary UI”, or “tests pass locally” is not a platform constraint. A deferred feature is incomplete scope and remains blocked, rather than becoming an accepted deviation.
