## Platform deviation register

There are **no accepted domain behavior deviations** in this PR. A different runtime transaction API, native remote envelope, or absent Astro type generator needs adaptation evidence; it does not automatically authorize a behavior change.

For each proposed deviation add: stable ID; exact upstream source IDs and assertions; baseline behavior; proposed observable difference; documented SvelteKit/Node/Cloudflare constraint with authoritative source; alternatives considered; affected runtimes/users/data; parent decision; paired regression tests; migration and documentation requirements. Keep the status `proposed` until decided. “Simpler”, “Cloudflare-first”, “temporary UI”, or “tests pass locally” is not a platform constraint. A deferred feature is incomplete scope and remains blocked, rather than becoming an accepted deviation.
